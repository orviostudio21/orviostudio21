# Orvio Studio
### Do conceito ao clique.

Estúdio digital brasileiro focado em sites, landing pages e interfaces web para profissionais e pequenos negócios.

## O que fazemos
- Sites institucionais para apresentar negócios e serviços.
- Landing pages com conteúdo organizado e um objetivo claro.
- Interfaces responsivas e ajustes de navegação.

## Laboratório Orvio
Projetos demonstrativos criados para explorar soluções simples de desenvolvimento web. Não representam clientes reais.

| Projeto | Proposta |
|---|---|
| [Raiz — Landing de serviços](https://github.com/orviostudio21/landing-servicos) | Apresentação de serviços de uma marca fictícia de jardinagem |
| [Calculadora de orçamento](https://github.com/orviostudio21/calculadora-orcamento) | Estimativas com horas, taxa e custos adicionais |
| [Checklist de publicação](https://github.com/orviostudio21/checklist-publicacao) | Revisão de entrega com progresso salvo no navegador |

## Como trabalhamos
Conversa inicial → definição de escopo e prazo → desenvolvimento → revisão e entrega.

**Tecnologias:** HTML · CSS · JavaScript · React
